# ReadySetJob

취업·인턴 지원 현황과 자기소개서 버전을 관리하는 웹 애플리케이션입니다.

## 실행 방법

1. 의존성 설치
```bash
npm install
```

2. 환경 변수 설정 (선택)
```bash
cp .env.example .env
```

3. 데모 데이터 시드 (기본 계정: `demo@readysetjob.dev` / `demo1234!`)
```bash
npm run seed
```

4. 서버 실행 (기본 포트: `3000`)
```bash
npm start
# 또는 개발 모드 (자동 재시작)
npm run dev
```

5. 테스트 실행
```bash
npm test
```
